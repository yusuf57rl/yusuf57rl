<summary><b>How I work</b></summary>
<br>

- **Frontend:** Next.js, React, Vue and Nuxt with TypeScript for interfaces that are fast, accessible and don't feel like a template.
- **Backend:** Node.js, Go and Python for services and APIs, Python for automation and AI glue. PHP with Laravel or Symfony where an existing project calls for it.
- **Systems:** C, C++ and Rust for the parts where performance and memory actually matter.
- **AI:** LLM integrations, RAG and semantic search on vector databases like Qdrant, wired into real products instead of demos.
- **AI in production:** LivaLink has an AI phone assistant that transcribes with whisper.cpp, books appointments and answers in a natural voice. Livi, the in-app assistant, helps set up shop, profile and settings and makes changes on request, always after confirmation.
- **Self-hosted AI:** Open-source models such as Llama, Mistral and Whisper, run locally with Ollama. Currently working with NVIDIA Triton on Kubernetes to serve them at scale.
- **Data:** PostgreSQL first, relational by default. MongoDB, Redis and Elasticsearch when the data is document-shaped, needs caching or needs search.
- **Shipping:** Containerised deployments behind Cloudflare, with CI/CD through GitHub Actions. On other projects I've also worked with AWS and Kubernetes. I build it, I run it, I fix it at 2 a.m.
- **Security and privacy:** GDPR-conscious by default: EU hosting, data processing agreements, minimal data collection.
- **AI-ready sites:** Clean structured data, machine-readable content and MCP APIs, so AI assistants can find, understand and use a site. LivaGlow is my reference: ChatGPT and other assistants create mug designs through its MCP API, and customers find it through them.
- **Performance and SEO:** Fast, accessible, well-structured sites that get found: Core Web Vitals, semantic markup, structured data.
- **Real time:** WebSockets and WebRTC for live features such as multiplayer, voice and video.
- **Payments and auth:** Shops, checkouts and secure sign-in, including OAuth and calendar integrations.
- **Monitoring:** Logs, metrics and alerts (Grafana, Prometheus) so problems show up before customers notice them.

</details>
